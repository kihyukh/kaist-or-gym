# Generated coffee demonstrations

These five recordings were generated by `kaist_rl_lab.apps.coffee_expert`, not
submitted by students. They are optional fallback teaching data for an instructor
who wants to demonstrate behavior cloning before a class has collected examples.

Each starts with the exact browser layout, an empty cup, 1.2 L in the pot, and the
700 mL target. The generator issues six normalized angular-velocity commands to
the original `CoffeePouringEnv` at 32 Hz. It does not change physics, liquid amounts,
recorded observations, collision rules, or success criteria. An inverse-kinematics
controller positions the vessels, slowly tilts the pot along a constant-spout
path, then returns it upright. Five approach/pouring speeds give distinct attempts.

Regenerate with `python -m kaist_rl_lab.apps.coffee_expert`. The web server reads the
packaged recordings; it does not need to run this controller. Tests replay every
recorded action from the ordinary student start and compare every observation.

The cloning policy trains only on recorded observation/action pairs. Performance
from this shared, deterministic starting layout is a classroom imitation demo,
not evidence that the cloned policy can handle new layouts or disturbances.
